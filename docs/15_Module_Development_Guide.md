# Module Development Guide

# Purpose

Every feature in IPO Genius AI must follow the same development process.

Complete one module before starting the next.

Never leave a module half finished.

# Module Checklist

## 1. Requirements

- Understand the feature.
- Define the expected outcome.
- Identify dependencies.

---

## 2. UI Design

- Create responsive layout.
- Reuse existing components.
- Follow UI/UX guidelines.
- Support Light & Dark Mode.

---

## 3. Frontend

- Create pages.
- Create components.
- Connect APIs.
- Handle loading states.
- Handle empty states.
- Handle error states.

---

## 4. Backend

- Create API routes.
- Create controllers.
- Create services.
- Create repositories.
- Validate requests.
- Return standard responses.

---

## 5. Database

If required

- Create tables.
- Add relationships.
- Create migrations.
- Add indexes.

---

## 6. API Integration

- Connect frontend to backend.
- Handle success responses.
- Handle error responses.
- Validate data.

---

## 7. Testing

Verify

- UI
- APIs
- Database
- Validation
- Responsive Design

Fix all bugs before continuing.

---

## 8. Deployment

- Build frontend.
- Build backend.
- Run migrations.
- Deploy successfully.

---

## 9. Module Complete

A module is complete only when

- Feature works.
- No build errors.
- No TypeScript errors.
- No lint errors.
- Responsive on all devices.
- API integrated.
- Database updated.
- Tested successfully.

---

# Coding Rules

Always

- Write reusable code.
- Keep components small.
- Follow folder structure.
- Reuse existing services.
- Use TypeScript.
- Use Tailwind CSS.

Never

- Duplicate code.
- Hardcode values.
- Skip validation.
- Ignore errors.
- Break existing modules.

---

# Development Order

1. Requirements
2. UI
3. Frontend
4. Backend
5. Database
6. API
7. Testing
8. Deployment

Do not skip any step.
