- Fade
- Slide

- Scale

# UI Rules

Keep every page consistent.

Reuse components.

Never redesign an existing component without updating all usages.

Avoid unnecessary colors.

Maintain consistent spacing.

# Design Philosophy

Less is More.

Every screen should look modern, fast, clean, and professional.
